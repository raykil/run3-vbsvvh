# corrections

## The `from_jsonpog-integration` directory

The corrections in this sub directory come from `https://gitlab.cern.ch/cms-crossPOG/jsonpog-integration.git`.

### Leptons

We get the Muon and Electron SFs from the `cat` dir on `cvmfs`, as specified in [the documentation](https://cms-analysis-corrections.docs.cern.ch)

The `latest` dir is not used (in favor of the specific versions recommended as of Sep 9, 2026) as specified in the paths in the code.
